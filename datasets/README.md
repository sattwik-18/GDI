# GDI Testing & Evaluation Dataset Repository

## Dataset Categories

| Directory | Purpose / Category |
|---|---|
| `certificates/` | Single-page official certificates (diplomas, accreditation) |
| `degrees/` | Academic degree transcripts and diplomas |
| `transcripts/` | Multi-page academic or professional records |
| `invoices/` | Financial invoices and billing receipts |
| `forms/` | Structured and semi-structured application forms |
| `synthetic/` | Programmatically generated stress-testing documents |
| `future/` | Reserved for future Prototype 2+ evaluation samples |

## Security & Privacy Guidelines

- **NO copyrighted material**
- **NO personally identifiable information (PII)** or real patient data
- Use only synthetic, anonymized, or public domain sample documents.
