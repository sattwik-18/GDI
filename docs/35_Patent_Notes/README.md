## 4. Claim 1: Immutable Document Genome Extraction & Comparison

*System and Method for Constructing and Verifying High-Dimensional Document Genomes*

**Core Inventive Concept**:
A method comprising:
1. Ingesting an original reference document and normalizing it into multiple analysis rendering modalities.
2. Extracting a multi-dimensional feature vector (genome) spanning layout, typography, rendering, texture, frequency, noise, and micro-DNA dimensions.
3. Establishing a probabilistic natural variation model across multiple authentic document instances.
4. Comparing a submitted candidate document by evaluating Gaussian Z-score similarity relative to the natural variation model across all feature dimensions.
5. Sealing the resulting genome with an HSM-backed cryptographic signature for immutable verification.

---

## 5. Claim 2: Sub-Pixel Zernike Moment & Micro-DNA Verification

*System and Method for Sub-Pixel Document Boundary and Printing Dot Pattern Forensics*

**Core Inventive Concept**:
A method comprising computing high-order 2D Zernike moments along stroke boundaries to extract sub-pixel edge jitter, boundary continuous derivative metrics, and halftone line screen frequency (LPI) / angle metrics, detecting microscopic digital and physical copy forgeries.

---

## 6. Claim 3: Bayesian Multi-Engine Evidence Fusion & Divergence Scoring

*System and Method for Interpretable Multi-Engine Evidence Aggregation and Divergence Scoring*

**Core Inventive Concept**:
A method of combining heterogeneous forensic outputs using a hierarchical 5-level evidence multiplier, dynamic engine reliability priors, and an Engine Divergence Index ($D_{\text{engine}}$) that penalizes inter-engine disagreement to produce explainable authenticity verdicts.

---

## 7. Claim 4: Attributed Graph Matching for Spatial Layout Topology

*System and Method for Topological Document Verification via Attributed Graph Edit Distance*

**Core Inventive Concept**:
A method modeling document objects as nodes in a Delaunay Triangulation Graph and evaluating structural document integrity by computing Graph Edit Distance and Laplacian Spectral Eigenvalues relative to a verified original graph structure.
